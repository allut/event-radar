Reading the toggles. Strip imagery removes every photographic plate, so you can check the ticket's rule that imagery amplifies but is never load-bearing. Reduced motion applies the same collapse that prefers-reduced-motion: reduce does inside each artboard.

What is faked. Photography — the artboard sandbox cannot load external images, so every "photo" is a layered CSS gradient with film grain. Judge composition and scrim behaviour, not the picture. Everything else — counts, event titles, venues, times, prices, source names, schedule times — is real.
