# shared/ — single source of truth for i18n strings and cross-stack constants

This directory is the canonical source for all translation strings and cross-stack
configuration. Both the Python backend and the TypeScript frontend consume it via
committed generated modules — no runtime cross-directory imports, no deploy-config changes.

## Files

| File | Contents |
|------|----------|
| `i18n/en.json` | English UI strings (`"ui"`) + email/digest strings (`"email"`) |
| `i18n/et.json` | Estonian equivalents |
| `i18n/ru.json` | Russian equivalents |
| `calendar.json` | `day_names` and `month_names` per locale (backend email only) |
| `personas.json` | Persona slugs, emojis, display names, and vibes per locale |
| `app-config.json` | Cross-stack scalars: TTLs, weights, locale list, locale_code_map, signal/category/vibe taxonomies |
| `fixtures/*.json` | Test cases both suites run, so a shared pattern behaves the same in Python and JS (not generated) |

## Workflow

```
1. Edit the JSON file(s) in shared/
2. python scripts/generate_shared.py
3. git add shared/ backend/app/_generated/ frontend/src/_generated/
4. git commit
```

To move an existing backend constant into `scalars`, run
`python scripts/move_to_shared.py <domain> NAME [NAME ...]` (add `--dry-run` to preview).
It adds the value, removes the backend definition and any same-named frontend copy,
regenerates, and repoints both stacks' imports. It prints the comments that sat above
each removed definition for you to place, flags changed gitignored files, and lists
frontend constants with the same value under another name, which it leaves alone.

## Generated outputs

| Generated file | Stack | Contents |
|----------------|-------|----------|
| `backend/app/_generated/i18n_data.py` | Python | `TRANSLATIONS` (email), `DAY_NAMES`, `MONTH_NAMES`, `PERSONAS` |
| `backend/app/_generated/shared_constants.py` | Python | Scalars, frozensets (TTLs, weights, locales, signals, categories, vibes) |
| `frontend/src/_generated/i18nData.ts` | TypeScript | `TRANSLATIONS` (UI), `PERSONA_TRANSLATIONS`, `PERSONAS_EN` |
| `frontend/src/_generated/sharedConstants.ts` | TypeScript | Scalars, `LOCALES`, `LOCALE_CODE_MAP` |

Generated files carry `AUTO-GENERATED by scripts/generate_shared.py — DO NOT EDIT.`
at the top. Edits to `_generated/` will be overwritten on the next generator run.

## Drift guard

`backend/tests/test_generated_sync.py` fails if committed `_generated` files diverge
from what the generator would produce today. Run the generator and commit to fix it.

## What stays stack-native

- Backend: all HTTP/retry constants, LLM prompts, scoring weights, scraper config,
  `TALLINN_TZ`, admin limits, auth salts, time-slot enums, PERSONA_*_AFFINITY settings.
- Frontend: `CATEGORY_GRADIENTS`, animation/timeout ms, React Query knobs, storage keys,
  `SIGNAL_CONFIG`, `toLocaleCode`, TypeScript `type` unions.
